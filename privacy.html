Inbox Operator Privacy Policy

Last updated: May 6, 2026

Inbox Operator helps users draft and review email replies before sending. This page is a starter privacy policy for prototype and showcase use.

What data the app uses

  • Email message metadata and message content needed to generate drafts.
  • Sender identity settings, approval policy settings, and local app preferences.
  • OAuth tokens for connected providers when a user chooses to connect Gmail or Outlook.

How data is used

  • To fetch inbox messages from connected providers.
  • To generate AI-assisted or template-based draft replies.
  • To let users review, approve, revise, or auto-send replies based on policy.

Storage

In this prototype build, settings and local state are stored on the host machine. This version is intended for demonstration and testing, not for production-grade secret management.

Third-party services

  • Google OAuth and Gmail API when Gmail is connected.
  • Microsoft OAuth and Microsoft Graph when Outlook is connected.
  • OpenAI API when a user enables AI drafting with their own API credentials.
